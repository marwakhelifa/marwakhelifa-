## Projet IA : AI Personal Agent

Assistant téléphonique qui prend des rendez-vous par la voix. L'appelant parle en darija, en arabe ou en français ; l'agent comprend la demande avec un LLM (Llama 3.3 via Groq), pose les questions manquantes, mémorise les préférences de l'utilisateur et ajoute le rendez-vous dans Google Calendar.

- Appels téléphoniques réels (Twilio Voice) et dialogue multi-tours
- Mémoire des préférences par utilisateur (SQLite)
- Déploiement possible sur Render
- **Réalisation :** projet personnel, conçu et développé seule

**Technologies :** Python · FastAPI · Twilio · Groq (Llama 3.3) · Google Calendar API · SQLite

[Code source](https://github.com/marwakhelifa/ai-personal-agent)
